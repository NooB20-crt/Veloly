# Listen offline

Veloly’s offline mode is for music files in your local library. It does not save streams from YouTube, Deezer, Spotify, or other online services for offline playback.

## Add your own files

1. Open **Library**.
2. On desktop, add the folder that contains your audio files. On mobile, choose **Add audio files** and select tracks in the system file picker.
3. Start playback from the local library. On mobile, selected files are copied into Veloly’s private app storage.
4. Turn on **Offline mode** to limit playback to music available locally.

The **Need help to do it?** action in the offline/library interface opens the in-app guide. The exact system picker steps can differ between Android, iOS, and desktop.
