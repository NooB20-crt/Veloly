# Lyrics

Veloly looks up lyrics when you open the lyrics view. Results depend on the lyric providers, their catalog, and the track metadata.

## Follow synchronized lyrics

When synchronized timing is available, the current line is highlighted as the song plays. Select a line to seek to it. Use the sync adjustment control if the lyrics consistently appear early or late.

## If lyrics do not appear

Check the song title and artist, make sure you are online, then use **Retry** if it is shown. Some tracks have no lyrics in the providers Veloly can access, or only have unsynchronized text. The previous song’s lyrics should not be treated as the current track’s result.
