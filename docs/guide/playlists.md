# Playlists and queue

## Create and edit playlists

Create a playlist from the Library, add tracks from their **More** menu, and drag tracks to reorder them. The same song can appear more than once in a playlist. Use the playlist’s sort controls to order tracks by name, album, or duration.

## Import a playlist

Choose **Import playlist** and paste a supported Spotify, Deezer, YouTube Music, or Veloly playlist link. Imported online entries are matched to tracks available to Veloly; an import link does not provide access to paid or private catalog content.

## Share a Veloly playlist

Use the playlist’s share action to create a link, then send it to someone. Creating and opening the link require an internet connection. A shared playlist contains track metadata; it does not upload local audio files or expose local file paths. The recipient may need to locate unavailable tracks in their own library.

## Back up or move a collection

In **Settings → Collection backup**, export the collection to a file. On another device, import that file from the same section. A backup is a file transfer; it does not continuously synchronize devices.

## Queue order

In **Queue → Next Up**, drag the handle next to a track to move it. Use **Save** if you want to preserve the queue as a playlist.
