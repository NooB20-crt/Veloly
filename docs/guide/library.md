# Your music library

## Add music

On desktop, open **Library** and add a music folder. Veloly scans supported audio files and shows them alongside online music.

On mobile, use **Add audio files** to choose files with the system file picker. Veloly imports a copy into its private app storage so the tracks remain available to the app. Mobile file pickers do not provide the same persistent folder access as desktop folder selection.

## Supported formats

Common supported formats include MP3, FLAC, OGG/OGA, M4A/MP4, AAC, WAV, AIFF, CAF, MKA, and WEBM. Actual playback can depend on the platform’s audio decoder.

## Missing files

If a desktop file or folder is moved or deleted outside Veloly, the library entry may no longer play. Restore the original location or remove and add the folder again. Removing a folder from the library does not delete the original music files.

## Collection data

Likes, playlists, and listening history are stored locally in the app’s collection data. Use **Settings → Collection backup** to export a backup before moving to another device.
