# Install Veloly

Veloly builds are published on the [GitHub Releases page](https://github.com/zyndrax707/Veloly/releases). Choose the package for your device.

## Windows

1. Download the latest `-setup.exe` installer.
2. Open it and follow the installation prompts.
3. If Windows SmartScreen warns that the app is not recognized, check that you downloaded it from the Veloly releases page before choosing **More info → Run anyway**.

## macOS

1. Download the `.dmg` for your Mac (Apple Silicon or Intel).
2. Open the disk image and move Veloly to Applications.
3. The build may be unsigned. If macOS blocks it, use Finder’s **Open** action from the app’s context menu after verifying the release source.

## Android

1. Download the Android `.apk` from Releases and open it on your device.
2. Allow your browser or file manager to install apps if Android asks.
3. To update, open the newer APK and confirm the system installer prompt. Android requires this confirmation.

## iPhone and iPad

The `.ipa` is installed with [SideStore](https://sidestore.io), using your Apple Account to sign the app. Follow the [Veloly iOS installation guide](https://zyndrax707.github.io/Veloly/ios.html). SideStore requires periodic renewal; its own guide explains the steps.

## Updates

Veloly checks for updates when supported by the platform. Desktop updates may be installed from the app when a signed updater package is available. Android opens the system installer for confirmation. iOS updates are managed through SideStore. See [Troubleshooting](./troubleshooting) if an update cannot be installed.
