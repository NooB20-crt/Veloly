# Keep themes portable

Veloly stores installed themes and Custom CSS in the app's local WebView storage. They are not uploaded or synchronized to another device.

## Keep a copy of a theme

Keep the original `.css` file you imported. To save Custom CSS as a file, copy it from **Settings → Personalization → Custom CSS** into a text editor and save it with a `.css` extension. That file can be imported into Veloly on another device.

You can share the `.css` file yourself using any method you choose. Veloly does not send it to a gallery or community service.

## Respect the stylesheet's terms

Only redistribute CSS you wrote or have permission to share. If a stylesheet is adapted from another project, preserve its license notices and attribution.
