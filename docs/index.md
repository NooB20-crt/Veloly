## Welcome to Veloly

Veloly is an independent music player based on [555](https://github.com/amonre555/555). It is not affiliated with the 555 project. This documentation explains how to install Veloly, manage your music, and use the player on desktop and mobile.

::: tip Need help getting started?
Begin with [Install Veloly](./guide/install), then add a local music folder or search for a track.
:::
